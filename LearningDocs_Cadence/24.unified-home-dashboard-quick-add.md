# Chunk 24: Unified Home Dashboard & Global Quick-Add

Tags: `#dashboard #quick-add #ui #ux #command-palette #integration #circadian #riverpod`

## Recap of Chunk 23 & Connection to Chunk 24
In Chunk 23, we implemented Biometric Security and Universal JSON Data Sovereignty, securing local SQLite tables with hardware authentication (`local_auth 3.x`) and enabling complete offline data backup and restoration.
Chunk 24 addresses the primary usability challenge of a feature-rich personal operating system: unifying disparate domains (habits, journal, movement, finance, routines, study, calendar, screen-time) into a coherent, daily "command center". It delivers an adaptive **Unified Home Dashboard** and a **Global Quick-Add Command Modal** that lets users dispatch cross-module actions from anywhere on the home screen with one tap.

---

## What this chunk does
1. **Unified Home Dashboard**:
   - **Hero Circadian Greeting**: Dynamic greeting ("Good Morning", "Deep Focus Phase", "Rest & Recovery") with phase color pills, formatted current date, and live sync status.
   - **Daily Vitals Glance Bar**: Real-time summary chips aggregating today's key metrics:
     - 📱 Screen Time today (from Drift `screen_time_snapshots`).
     - 💸 Expenses logged today vs Monthly Budget progress.
     - ⏱️ Pomodoro / Study minutes accrued today.
     - ✅ Routine completion count / percentage.
   - **Integrated Domain Modules**: Consolidates `FocusTimerCard`, `GoalsOverviewSection`, `ScreenTimeCard`, and `EntriesFeed` into a clean, unified scrolling dashboard.
2. **Global Quick-Add Modal (`GlobalQuickAddModal`)**:
   - Replaces single-purpose FAB with a modern command palette bottom sheet offering 6 rapid actions:
     - 📝 **Log Thought / Habit**: Opens `QuickLogModal` (water, mood, sleep, habits, reflection).
     - 💸 **Log Expense**: Opens `AddExpenseSheet` to record financial outflow.
     - ⏱️ **Focus Timer**: Initiates a 25-minute Pomodoro focus block.
     - 📍 **Record Route**: Jumps to Movement view and readies GPS activity tracking.
     - 🤝 **Record Debt / IOU**: Opens `CreateDebtDialog` for peer lending or borrowing.
     - 📅 **Schedule Event**: Opens `CreateEventDialog` for time-blocking on calendar.
3. **Seamless Dashboard-to-Tab Navigation**:
   - Allows quick-action tiles to seamlessly switch bottom navigation tabs (e.g. to Movement or Planner) or open dialog sheets without deep routing boilerplate.

---

## Why it's needed
As an offline personal OS grows from a simple habit tracker into a comprehensive suite (GPS GIS mapping, double-entry debt ledgers, calendar time-blocking, screen-time analytics, circadian themes), navigation fatigue becomes the primary user bottleneck. If logging an expense requires tapping the Finance tab, scrolling past net worth charts, and finding the add button—or if starting a walk requires switching to Movement—the app becomes too heavy for daily capture.
A true "personal operating system" must offer **two-second capture latency** for any life event, paired with an executive daily glance that summarizes the user's current status at a glance.

## How to think and write this code manually (Mental Algorithm)

### Step 0: What problem are we solving?
Users need a central command dashboard on the Today tab that highlights key vitals across all life domains, and a global action launcher to capture events in under 2 seconds.

### Step 1: Input shape & contract (Action Definitions)
Define a lightweight data structure `QuickAddAction`:
- `title`: String (e.g. 'Log Expense')
- `subtitle`: String (e.g. 'Record transaction')
- `icon`: IconData
- `color`: Color
- `onTap`: VoidCallback

### Step 2: Business & database logic (Providers & Vitals)
- `todayVitalsSummaryProvider`: Aggregates today's spent amount, screen time duration, completed routines count, and total focus minutes into a single lightweight model `DailyVitalsSummary`.

### Step 3: Route & security (Presentation)
- `GlobalQuickAddModal`: Clean Material 3 Modal Bottom Sheet with rounded corners, expressive icons, and ripple animations.
- `TodayVitalsBar`: Horizontal scroll / wrap row of compact glance chips on `DashboardScreen`.
- Wire the floating action button on `DashboardScreen` to `GlobalQuickAddModal.show(context)`.

### Step 4: Dependency wiring (Module)
- Connect callbacks to tab switching (`onNavigateToTab(index)`) so actions like "Record Route" smoothly change the active tab index.

## SQL Under the Hood (Cross-Module Daily Vitals Query)

```sql
-- Today's Total Expenses
SELECT COALESCE(SUM(amount), 0.0) 
FROM expenses 
WHERE date >= '2026-09-08 00:00:00' AND date <= '2026-09-08 23:59:59';

-- Today's Screen-Time
SELECT COALESCE(total_usage_seconds, 0) 
FROM screen_time_snapshots 
WHERE date = '2026-09-08' 
LIMIT 1;

-- Today's Completed Routines
SELECT COUNT(DISTINCT routine_id) 
FROM routine_completions 
WHERE completed_at >= '2026-09-08 00:00:00';
```

## The Edge Case & Error Matrix

| Input Condition / Failure Mode | Handling Component | Resulting Behavior |
|---|---|---|
| User triggers quick action while modal is animating | `GlobalQuickAddModal` | Uses `Navigator.of(context).pop()` first, then triggers destination action on next frame via `Future.microtask`. |
| Cross-module aggregation returns null (e.g. fresh database) | `DailyVitalsSummary` | Gracefully defaults all numeric values to zero (`0m`, `$0.00`, `0%`) without null errors. |
| User triggers route recording from dashboard | Tab Navigator Callback | Smoothly navigates to tab 2 (Movement) and brings tracking card into view. |

## Why NOT Do It This Other Way? (Anti-Patterns & Alternatives)

- **Why NOT put 6 separate floating action buttons or an expander dial (speed dial) on the screen?**
  - Speed dials clutter the UI, obscure content underneath, and cause accidental touches. A clean modal bottom sheet adheres to Material 3 guidelines and provides clear labels and icons.
- **Why NOT force users to visit each feature tab to create records?**
  - Fragmented navigation creates high cognitive friction. Quick logging must be universal and accessible from the home screen.

## How it works
1. Tapping the FAB on `DashboardScreen` opens `GlobalQuickAddModal`.
2. The modal displays 6 categorized action cards.
3. Tapping an action dismisses the modal and opens the appropriate workflow (e.g. `AddExpenseSheet`, `CreateEventDialog`, `QuickLogModal`, `CreateDebtDialog`, or switches to the Movement tab).
4. The Today view hero section displays real-time vitals chips showing today's screen time, expenses, focus time, and routine completion.

---

## Gotchas / trade-offs
- **Context Invalidity after Modal Dismissal**: Tapping a button in a modal sheet pops the modal route. If a subsequent dialog is opened using the modal's `BuildContext`, it will throw `Looking up a deactivated widget's Ancestor`. Solution: Pass the root/parent `context` or close the modal and use the outer scaffold context.

## Check yourself (Inline Evaluation)
